# AI 发展

两个大趋势：LLM 或者 stable diffusion，即大语言模型和用于生成图片

## Stable diffusion
- 开源
- 文本转图片
- 图片高质量
- 快速高效
- 灵活性、创造性（可以创建各种风格的图片）
- 多样化、持续改进

### 基于 Stable diffusion 的项目
https://github.com/topics/stable-diffusion

# 工具
## replicate.com 
- Provide Cloud machine to run models easier
Replicate 是一个旨在让所有软件开发者轻松使用 AI 的平台。它提供了一个丰富的开源机器学习模型库，开发者可以通过简单的 API 调用，在云端运行这些模型

## huggingface.co
- Provide Cloud machine to run models easier
Hugging Face 是一个致力于推动人工智能（AI）开放研究和应用的平台。它为机器学习社区提供了一个协作平台，用户可以在此创建、分享和使用 AI 模型、数据集和应用程序。

## segment-anything.com
- Cut out any object in any images
用户可以通过简单的点击，在任何图像中“剪切”出任意对象

## EditAnything
- Combine many models/libs related to image to one praject
旨在通过结合多种先进的人工智能模型，实现对图像中任意元素的编辑和生成

## Auto Designer
- A service could create Mobile/Website Ul in one click
- https://uizard.io/autodesigner/
旨在通过简化用户界面（UI）设计过程，帮助用户快速创建和迭代设计原型。该工具结合了生成式设计能力和对话式 AI，用户可以通过简单的文本描述，生成多屏幕的应用或网站原型。

## Genmo
- Text to Video / Image to Video
- https://www.genmo.ai/
专注于开发开放的视频生成模型，旨在模拟任何场景，推动具身 AI（Embodied AI）的发展
